=============================================================================
Service Endpoints
=============================================================================

{{- if .Values.ingress.enabled }}
Ingress is ENABLED. Add the following lines to /etc/hosts (or your DNS):
  <INGRESS_EXTERNAL_IP>  {{ .Values.ingress.apiHost }}
  <INGRESS_EXTERNAL_IP>  {{ .Values.ingress.appHost }}

  Frontend : http://{{ .Values.ingress.appHost }}
  API      : http://{{ .Values.ingress.apiHost }}

To find the Ingress external IP:
  kubectl get ingress -n {{ .Release.Namespace }} artacademy-ingress
{{- else }}
Ingress is DISABLED. Access services via port-forward or LoadBalancer IPs:

  kubectl get svc -n {{ .Release.Namespace }}
{{- end }}

=============================================================================
Quick Port-Forward Commands
=============================================================================

  # Eureka Dashboard
  kubectl port-forward -n {{ .Release.Namespace }} svc/service-registry 8761:8761

  # API Gateway
  kubectl port-forward -n {{ .Release.Namespace }} svc/api-gateway 8080:8080

  # Frontend
  kubectl port-forward -n {{ .Release.Namespace }} svc/frontend-react 3000:80

=============================================================================
Checking Pod Status
=============================================================================

  kubectl get pods -n {{ .Release.Namespace }}
  kubectl get pods -n {{ .Release.Namespace }} -w   # watch

=============================================================================
Viewing Logs
=============================================================================

  kubectl logs -n {{ .Release.Namespace }} -l app=api-gateway --tail=100 -f
  kubectl logs -n {{ .Release.Namespace }} -l app=auth-service --tail=100 -f

=============================================================================
Upgrading the Release
=============================================================================

  helm upgrade {{ .Release.Name }} ./helm \
    --namespace {{ .Release.Namespace }} \
    --set image.tag=<NEW_TAG>

=============================================================================
Uninstalling
=============================================================================

  helm uninstall {{ .Release.Name }} --namespace {{ .Release.Namespace }}

NOTE: Persistent volumes (PostgreSQL data) are NOT deleted automatically.
      Delete them manually if you want a clean teardown:
        kubectl delete pvc -n {{ .Release.Namespace }} postgres-pvc
